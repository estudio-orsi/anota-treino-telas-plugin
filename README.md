# Anota Treino — Telas Login e Onboarding (Penpot)

Monta as telas de login, cadastro, esqueci a senha, onboarding e estados de erro do Anota Treino, usando cópias dos componentes da biblioteca "Anota Treino - Biblioteca".

Como usar:
1. Abra o arquivo "Login + Onboarding" no Penpot, com a biblioteca "Anota Treino - Biblioteca" conectada.
2. Aperte Ctrl+Alt+P e cole o endereço:
   https://estudio-orsi.github.io/anota-treino-telas-plugin/manifest.json
3. Abra o plugin.
   - "Diagnóstico": só lê a biblioteca e o arquivo, não muda nada. Mostra as contagens.
   - "Montar Login + Onboarding": cria ou refaz as páginas.
   - "Baixar log": salva um arquivo .json com o diagnóstico e o log completo da última montagem.

O plugin só roda nesse arquivo e com a biblioteca conectada. Ao rodar de novo, ele apaga e refaz só as páginas que ele mesmo criou.
A permissão "allow:downloads" serve só para o botão "Baixar log".
